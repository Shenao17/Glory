# ♡ Para Glorita

Una pequeña página web hecha con mucho cariño para una persona muy especial.

## 💙 Sobre el proyecto

Esta página nació con una idea muy sencilla: crear un pequeño espacio dedicado a Glorita para recordarle lo importante que es para mí.

No fue creada por una fecha especial, un aniversario o alguna celebración. Simplemente un día quise hacer algo diferente y dejar en algún lugar unas palabras que quizá no siempre sé cómo expresar.

La página busca ser más que una simple carta. Es una pequeña experiencia interactiva con mensajes, animaciones y detalles inspirados en una estética de cielo, nubes y Cinnamonroll.

Cada parte fue pensada para que al recorrerla se sienta como un pequeño regalo hecho especialmente para ella. ♡

---

## ✨ Características

- Página completamente estática.
- Diseño inspirado en tonos celestes, blancos y rosados.
- Elementos visuales inspirados en Cinnamonroll.
- Animaciones y transiciones suaves.
- Mensajes interactivos.
- Pequeños detalles y easter eggs escondidos en el código.
- Favicon personalizado.
- Diseño adaptable para dispositivos móviles y escritorio.
- Sin necesidad de backend o base de datos.

---

## 🛠️ Tecnologías utilizadas

El proyecto fue construido utilizando únicamente tecnologías web básicas:

- **HTML5** — estructura y contenido.
- **CSS3** — diseño, animaciones y estilos.
- **JavaScript** — interactividad y comportamiento de la página.
- **Git / GitHub** — control de versiones.
- **GitHub Pages** — publicación y alojamiento.

No se utilizaron frameworks ni librerías externas.

La intención fue mantener el proyecto sencillo, ligero y completamente estático.

---

## 📁 Estructura del proyecto

La estructura principal del proyecto es:

**glorita/**
- `index.html` — página principal.
- `style.css` — estilos, diseño y animaciones.
- `script.js` — interactividad y lógica.
- `README.md` — documentación del proyecto.
- `assets/icon.png` — favicon de la página.

## 💌 ¿Por qué existe esta página?

Porque algunas personas terminan ocupando un lugar demasiado importante en nuestra vida como para limitar todo lo que significan a unas pocas palabras.

Esta página es una forma de decir:

> "Quizá no siempre sepa cómo expresarlo, pero eres una persona muy importante para mí."

No pretende ser perfecta.

De hecho, parte de su encanto está precisamente en que fue hecha de forma personal, aprendiendo y probando cosas hasta conseguir algo que se sintiera correcto.
